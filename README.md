# Python Math Quiz

A simple console-based math quiz built with Python. The program generates random arithmetic problems, checks user answers, tracks incorrect attempts, and measures completion time.

## Features

* Generates random addition, subtraction, and multiplication problems
* Provides 10 questions per quiz
* Validates user answers
* Tracks incorrect attempts
* Calculates quiz completion time
* Displays the final score

## Technologies

* Python
* `random` module
* `time` module
* Functions
* Loops and conditional logic
* User input and validation

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python_math_quiz.py
```

## Purpose

This project was created to practice fundamental Python programming concepts, including functions, loops, conditional logic, randomization, user input, and basic performance tracking.
